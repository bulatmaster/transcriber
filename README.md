# Транскрибатор

Локальное GNOME-приложение для просмотра видео/аудио, CPU-транскрибации и ведения заметок по файлам. Программа не отправляет медиа в облако и не создает служебные файлы в папке с исходниками.

## Что умеет

- Показывает видео и аудио из выбранной папки.
- Сортирует список файлов от новых к старым.
- Показывает тип файла, длительность, дату файла, статус расшифровки и превью.
- Воспроизводит видео/аудио внутри приложения через GTK4/GStreamer.
- Поддерживает перемотку и скорость `1x`, `1.5x`, `2x`, `3x`.
- Открывает выбранный файл в файловом менеджере через кнопку `Показать в папке`.
- Транскрибирует локально через `faster-whisper` на CPU.
- Для видео сначала извлекает звук во внутреннюю служебную папку.
- Использует VAD-фильтр, чтобы уменьшить мусорные фразы Whisper на тишине.
- Добавляет шапку к расшифровке с типом, именем файла и датой файла.
- Сохраняет заметки автоматически при вводе.
- Поддерживает режим `Авто`, который транскрибирует новые файлы в выбранной папке.
- Позволяет переименовать или удалить файл через контекстное меню по правому клику.
- Сохраняет расшифровку при ручном переименовании исходного файла.

## Для кого это приложение

Приложение рассчитано прежде всего на Linux с GNOME или близким GTK-окружением. Лучше всего подходит для Ubuntu/Debian GNOME, Fedora Workstation, Arch/Manjaro GNOME.

На KDE, Xfce или минимальных Linux-сборках тоже может работать, но нужно вручную поставить GTK4, libadwaita, GStreamer и нужные плагины.

## Быстрый старт

```bash
git clone https://github.com/bulatmaster/transcriber.git
cd transcriber
./install.sh
```

После установки ищите приложение в меню GNOME как `Транскрибатор`.

Первый запуск транскрибации скачает модель Whisper из интернета. Само распознавание после этого выполняется локально.

## Что нужно установить в системе

Нужны системные компоненты:

- `python3`
- `python3-venv`
- `python3-gi`
- GTK4
- libadwaita
- GStreamer
- GStreamer GTK4 sink
- `ffmpeg` и `ffprobe`
- интернет для первой загрузки модели Whisper

Python-зависимости из `requirements.txt` ставятся в локальное `.venv` внутри проекта.

## Установка системных зависимостей

Debian/Ubuntu:

```bash
sudo apt update
sudo apt install ffmpeg python3-venv python3-gi gir1.2-gtk-4.0 gir1.2-adw-1 gstreamer1.0-gtk4
```

Fedora:

```bash
sudo dnf install ffmpeg python3-gobject gtk4 libadwaita gstreamer1-plugins-bad-free
```

Arch Linux / Manjaro:

```bash
sudo pacman -S ffmpeg python-gobject gtk4 libadwaita gst-plugin-gtk
```

Если `ffmpeg` в Fedora недоступен из стандартных репозиториев, включите RPM Fusion и установите `ffmpeg` оттуда.

## Что делает install.sh

`install.sh`:

- проверяет наличие `python3`, `ffmpeg`, `ffprobe`, GTK4, libadwaita и GStreamer;
- создает виртуальное окружение `.venv` внутри папки проекта;
- устанавливает Python-зависимости из `requirements.txt`;
- копирует иконку в `~/.local/share/icons/hicolor/scalable/apps/`;
- создает desktop-файл `~/.local/share/applications/io.github.bulat.Transcriber.desktop`;
- обновляет кэш иконок и меню, если соответствующие утилиты есть в системе.

Если после установки пункт меню не появился сразу, выйдите из GNOME-сессии и зайдите обратно.

## Запуск без установки в меню

Можно запустить напрямую из папки проекта:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python3 app.py
```

Важно: приложение запускается системным `python3`, потому что GTK/libadwaita обычно установлены как системные GI-биндинги. Код автоматически добавляет `.venv` в `sys.path`, чтобы находить `faster-whisper` и остальные pip-зависимости.

## Как пользоваться

1. Запустите `Транскрибатор` из меню GNOME или командой `python3 app.py`.
2. Нажмите `Выбрать папку`.
3. Выберите папку, где лежат видео или аудио.
4. Выберите файл слева.
5. На вкладке `Просмотр` можно воспроизвести файл, перемотать, изменить скорость и показать файл в папке.
6. На вкладке `Расшифровка`, если текста еще нет, нажмите `Транскрибировать`.
7. На вкладке `Заметки` можно писать произвольные заметки. Они сохраняются автоматически.
8. По правому клику на файл доступны действия `Транскрибировать` или `Открыть расшифровку`, `Переименовать`, `Удалить`.

## Как работает транскрибация

Для аудио приложение транскрибирует сам файл.

Для видео приложение сначала извлекает аудио через `ffmpeg` в WAV 16 kHz mono. Извлеченный звук сохраняется не рядом с исходником, а в служебной папке приложения.

Далее используется `faster-whisper`:

- модель: `base`;
- устройство: `cpu`;
- compute type: `int8`;
- количество CPU threads: до 4;
- `beam_size=1`, чтобы CPU-распознавание было быстрее;
- `vad_filter=True`, чтобы пропускать тишину;
- `condition_on_previous_text=False`, чтобы уменьшить повторения и мусорные фразы.

Это не самый точный режим Whisper, но он выбран как разумный баланс скорости и качества для CPU-only ноутбука с 8 GB RAM.

## Формат расшифровки

После успешной транскрибации текст сохраняется с шапкой:

```text
Расшифровка (видео) - example.mp4
Дата файла: 22.07.2026 15:30

Текст расшифровки...
```

Для аудио будет `Расшифровка (аудио)`.

## Где хранятся данные

Все служебные данные лежат здесь:

```text
~/.local/share/transcriber
```

Там находятся:

- SQLite-база с настройками, расшифровками и заметками;
- извлеченный звук из видео;
- превью видео;
- промежуточные файлы приложения.

Папка с исходными медиафайлами не засоряется.

## Как приложение переживает переименование файлов

Приложение привязывает данные не только к пути файла. Для файла считается стабильный идентификатор по размеру и нескольким фрагментам содержимого. Поэтому если переименовать исходное видео или аудио вручную, расшифровка и заметки должны сохраниться.

Если содержимое файла изменится, это уже будет считаться другим файлом.

## Удаление файла во время транскрибации

Если исходный файл удалили во время транскрибации, worker должен остановиться. Готовая расшифровка в этом случае не сохраняется как успешная.

## Режим Авто

Галочка `Авто` включает автоматическую транскрибацию новых файлов в выбранной папке.

Приложение периодически пересканирует папку. Если оно видит новый файл без расшифровки, запускает транскрибацию.

## Обновление приложения

```bash
cd transcriber
git pull
./install.sh
```

`install.sh` можно запускать повторно. Он обновит зависимости, desktop-файл и иконку.

## Удаление приложения

Удалить пункт меню и иконку:

```bash
rm -f ~/.local/share/applications/io.github.bulat.Transcriber.desktop
rm -f ~/.local/share/icons/hicolor/scalable/apps/io.github.bulat.Transcriber.svg
```

Удалить код:

```bash
rm -rf ~/Projects/transcriber
```

Удалить локальные данные приложения:

```bash
rm -rf ~/.local/share/transcriber
```

Осторожно: последняя команда удалит заметки и расшифровки.

## Диагностика проблем

Проверить системные зависимости GTK/libadwaita/GStreamer:

```bash
python3 - <<'PY'
import gi
gi.require_version('Gtk', '4.0')
gi.require_version('Adw', '1')
gi.require_version('Gst', '1.0')
from gi.repository import Gtk, Adw, Gst
print('GTK/libadwaita/GStreamer OK')
PY
```

Проверить `ffmpeg`:

```bash
ffmpeg -version
ffprobe -version
```

Проверить Python-зависимости:

```bash
. .venv/bin/activate
python -c "import faster_whisper; print('faster-whisper OK')"
```

Запустить приложение из терминала и увидеть ошибки:

```bash
python3 app.py
```

## Частые проблемы

### Приложение не появилось в меню GNOME

Запустите повторно:

```bash
./install.sh
```

Если не помогло, выйдите из GNOME-сессии и зайдите обратно.

### Ошибка `No module named gi`

Не установлены GI-биндинги Python. Установите системные зависимости для вашего дистрибутива из раздела выше.

### Ошибка про GTK, Adw или Gst

Не хватает GTK4, libadwaita или GStreamer. Установите системные зависимости для вашего дистрибутива.

### Видео не проигрывается

Проверьте GStreamer-плагины и `ffmpeg`. На некоторых дистрибутивах нужны дополнительные multimedia codecs или non-free репозитории.

### Кнопка транскрибации есть, но модель долго грузится

Первый запуск скачивает модель Whisper. Нужен интернет. После скачивания модель кешируется локально библиотеками Hugging Face.

### Транскрибация слишком медленная

Это CPU-only режим. Для длинных видео на слабом ноутбуке это может занимать много времени. В коде используется модель `base` и `int8`, чтобы не упираться в 8 GB RAM.

### Расшифровка содержит ошибки

Локальный Whisper на маленькой модели не идеален. Модель `base` выбрана ради скорости. Для лучшего качества можно изменить модель в `app.py`, но это увеличит время и потребление памяти.
