# Транскрибатор

Локальное GNOME-приложение для просмотра папки с видео/аудио, транскрибации на CPU и хранения заметок без мусора в исходной папке.

## Возможности

- Выбор папки с медиафайлами.
- Список видео/аудио с превью, длительностью, датой файла и статусом расшифровки.
- Сортировка файлов от новых к старым.
- Просмотр видео/прослушивание аудио внутри приложения через GTK4/GStreamer.
- Перемотка и скорость воспроизведения `1x`, `1.5x`, `2x`, `3x`.
- Кнопка `Показать в папке` для выбранного файла.
- Локальная CPU-транскрибация через `faster-whisper` в `int8` режиме.
- VAD-фильтр против артефактов Whisper на тишине.
- Автоматическая транскрибация новых файлов при включенном режиме `Авто`.
- Заметки по каждому файлу с автосохранением при вводе.
- Переименование и удаление файлов из контекстного меню.
- Корректная привязка расшифровок к файлам при ручном переименовании исходника.
- Служебные данные хранятся отдельно от исходной папки с медиа.

## Быстрая установка после clone

```bash
git clone https://github.com/bulatmaster/transcriber.git
cd transcriber
./install.sh
```

После установки приложение появится в меню GNOME как `Транскрибатор`.

## Ручная установка

Нужны `ffmpeg`, GTK4/libadwaita/GStreamer и Python 3.10+.

Debian/Ubuntu:

```bash
sudo apt install ffmpeg python3-venv python3-gi gir1.2-gtk-4.0 gir1.2-adw-1 gstreamer1.0-gtk4
```

Fedora:

```bash
sudo dnf install ffmpeg python3-gobject gtk4 libadwaita gstreamer1-plugins-bad-free
```

Arch Linux:

```bash
sudo pacman -S ffmpeg python-gobject gtk4 libadwaita gst-plugin-gtk
```

Python-зависимости:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python3 app.py
```

## Где хранятся данные

Служебные файлы, база, извлеченный звук, тексты и превью хранятся в:

`~/.local/share/transcriber`

Исходная папка с медиа не изменяется.

## Транскрибация

Используется `faster-whisper` на CPU в `int8` режиме с моделью `base` по умолчанию. Для ноутбука с 8 GB RAM это разумный баланс скорости и качества. VAD-фильтр включен, чтобы не получать типичные артефакты Whisper на тишине.

Первый запуск транскрибации скачает модель.

## Установка в меню GNOME

`install.sh` создает:

- виртуальное окружение `.venv` внутри проекта;
- desktop-файл `~/.local/share/applications/io.github.bulat.Transcriber.desktop`;
- иконку `~/.local/share/icons/hicolor/scalable/apps/io.github.bulat.Transcriber.svg`.

Если приложение не появилось в меню сразу, выйдите из GNOME-сессии и зайдите обратно.

## Обновление

```bash
git pull
./install.sh
```

## Данные приложения

Программа хранит базу, заметки, расшифровки, превью и извлеченный звук в:

`~/.local/share/transcriber`

Эту папку можно перенести отдельно, если нужно сохранить локальные данные между машинами.
